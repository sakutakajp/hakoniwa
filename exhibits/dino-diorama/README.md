# Jurassic River Diorama（ジュラ紀の川辺の箱庭）

暖かいベージュの床に置かれた、四隅の丸い正方形の地面の塊の上の、ジュラ紀の川辺の森の箱庭を Three.js で描画する Web ページです。
「淡い砂の角丸ミニチュア台座」（`sand-pedestal`）・「ニューヨークの箱庭」（`nyc-diorama`）・「図書館の箱庭」（`library-diorama`）とシリーズになるように、
台座（一辺 10・四隅の半径 1.2・木地の土台）・床・光・トーンマッピング・カメラ・水の色と描き方・画面と操作の作りをそろえています（縮尺は違います）。

- 手本：ご提供いただいた参考画像（恐竜のいる川辺の森の箱庭）。カメラは参考画像の台座の外形に合わせて求めた結果、シリーズと同じ向き・画角になった
- 地面の塊：上面は川辺の地形、切り口は暗い茶色の表土と、丸みのある石灰岩の塊を積んだ層（外周に沿って継ぎ目なく続く）
- 川：右奥の高台の林の中の湧き水から流れ出し、苔むした岩の転がる斜面を 3 段の滝になって落ちる。滝の下からは砂浜の左岸に沿って手前へ流れ、
  手前の中央右で切り口を横切る。川幅は滝の下から切り口まで、なめらかに少しずつ広がる（水際には小さな入り江と出っ張りのゆらぎ）。
  切り口はガラスのような水の断面になり、川底の砂と苔むした岩が透けて見える（左は砂浜から続くなだらかな斜面、右の壁は丸く川底へ曲がる）。
  川の形は、中心線に沿って並べた円（左右で半径が違う）を重ねた形として求めるので、曲がり角でも岸や川底に段や筋ができない
- 森：アラウカリア（輪生する枝が燭台のように反る）、マツ（雲形の枝葉の固まり）、明るい黄緑の広葉樹、右岸の少しのトウヒ。約 100 本。
  左奥の林は高い幹が並ぶ林で、林の中には背の低い植物を置かない（下草は林の縁だけ）。右岸の木は川岸から離して置き、川岸と水面が木の影で暗くならないようにする
- 下草：ソテツ、シダ、葉の茂み、地面の草むら
- 岩と小物：岸の丸い岩、滝の落ち口の両脇と滝つぼの岩、水から顔を出す濡れた岩、川底の苔むした岩、小石、右岸の倒木。
  川の中の石は群にまとめ（滝つぼ・左岸の上流の浅瀬・下流の右・手前の淵）、川の中ほどにはほとんど置かない
- 岸：左岸は広い砂浜。右岸は水際にところどころ砂地があり、砂地の所は岸がなだらかになる

箱庭はドラッグで回したり、拡大縮小したりして、好きな向きから眺められます。
葉・羽状の葉・樹皮・岩・地面・切り口の模様と影はすべて起動時にその場で生成するので、外部の画像素材は使いません。

## 恐竜を置く場所

恐竜は別に用意する 3D モデルを置く前提で、シーンには作っていません。参考画像の 5 頭の位置と大きさを `config.dinoSpots` に残し、
そこには木を置かず、体の下には下草も置かないで空けてあります（`src/dinoSpots.ts`）。

| 場所 | 体の中心 x, z | 地面の高さ | 向き | 尾の先まで／頭の先まで | 高さ |
| --- | --- | --- | --- | --- | --- |
| ブラキオサウルス（左岸で川の水を飲む） | 0.05, 0.04 | 1.52 | 47° | 2.33 ／ 1.6（口元は水面の 1.31, 1.565, 0.95） | 1.32 |
| ブラキオサウルス（奥の岸で首を上げて歩く） | 1.05, −3.55 | 1.82 | −5° | 1.89 ／ 0.98 | 1.75 |
| ブラキオサウルス（滝の上の高台、遠くの小さな一頭） | 3.75, −4.72 | 2.35 | 8° | 1.07 ／ 0.56 | 0.99 |
| ステゴサウルス（左手前の草地で草を食べる） | −2.94, 2.6 | 1.74 | 6° | 1.85 ／ 1.15 | 0.96 |
| ステゴサウルス（子ども） | −1.48, 1.94 | 1.77 | 10° | 0.82 ／ 0.51 | 0.43 |

- 座標はワールド座標（x は右、z は手前、y は上。台座の中心が原点で、上面の地面はおよそ y = 1.8）
- 向きは +x（画面の右）から +z（手前）へ回る角度。0° で右、90° で手前を向く
- 水を飲む恐竜の口元から広がる波紋は、`createWater` の戻り値の `setRing(x, z, 半径, 強さ)` で出せます（既定では出しません）

## 起動手順

Node.js 20.19 以上（または 22.12 以上）が必要です。

```bash
npm install
npm run dev       # 開発サーバー（表示された URL をブラウザで開く）
npm run build     # 型チェック + 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果の確認
```

表示には WebGL2 に対応したブラウザ（最近の Chrome / Safari / Firefox / Edge）が必要です。
起動時に影と空からの遮蔽を焼き込むので、表示までに数秒かかります（GPU のない環境では軽い設定に切り替わります）。

### 操作（シリーズ共通）

| 操作 | マウス・トラックパッド | タッチ | キーボード |
| --- | --- | --- | --- |
| 回す（まわりを回る・見下ろす角度を変える） | ドラッグ | 1 本指でドラッグ | ← → で回す、↑ ↓ で傾ける（Shift で大きく） |
| 拡大縮小（指した所に向かって） | ホイール・ピンチ | 2 本指でピンチ | ＋ ／ − |
| 平行移動 | 右ドラッグ・Shift＋ドラッグ | 2 本指でドラッグ | — |
| 元の向きに戻す | ダブルクリック | ダブルタップ | 0 または Home |

最初に開いたときだけ、画面の下に操作の案内が出ます（一度触ると、次からは出ません）。

### 確認用の URL パラメータ

| パラメータ | 内容 |
| --- | --- |
| `?az=0&el=22.8` | 始める向き（方位角・仰角、度） |
| `?hint=0` | 操作の案内を出さない |
| `?quality=high` / `?quality=low` | 画質を固定する。既定では GPU を使えない環境だけ自動で `low`（影の焼き込みを軽く）になる |
| `?water=0` / `?rocks=0` / `?plants=0` | 水・岩・植物を隠した状態で始める |
| `?waterTime=3` | 水の動きを止めて、その時刻で描く（見た目の確認用） |

## シリーズの共通仕様（ほかの箱庭と同じ所）

| 項目 | 内容 | 設定・ファイル |
| --- | --- | --- |
| 台座 | 一辺 10 の正方形、四隅とも半径 1.2。下に厚さ 0.255 の明るい木地の土台（`#a58c6a`、地面の塊より一辺の 1.2% 内側） | `config.pedestal`、`src/pedestal.ts` |
| 床 | 暖かい淡いベージュ（`#e2d6cf`）。遠くは背景の色（`#fae8d4`）に溶け込み、台座のまわりに柔らかい影 | `config.floor`、`config.renderer.background`、`src/floor.ts` |
| 光 | 右手前の高い所からの柔らかい主光、右奥からの補助光、空と床の色の半球光。影と空からの遮蔽は起動時に焼き込む | `config.lights`、`config.shadow`、`src/lightBaker.ts`、`src/bakedLighting.ts` |
| 仕上げ | 明るい所だけを丸めるトーンマッピング | `config.renderer`、`src/toneMapping.ts` |
| カメラと構図 | 仰角 22.8 度・画角 13.44 度・距離は台座の幅の 4.86 倍、手前の辺の正面（方位 0°）から。台座と木の上端が余白に収まるように合わせる | `config.camera`、`config.framing`、`src/framing.ts` |
| 水 | 浅瀬・中ほど・深場の色、透明度と吸収、さざ波、岸の泡、水の中の光の模様、断面の描き方 | `config.water`、`src/river/` |
| 画面と操作 | 背景・案内文の色、操作の案内、見る向きの操作 | `index.html`、`src/style.css`、`src/viewControls.ts` |

違うのは次の所です。

- **縮尺**：1 単位がおよそ 6 m（台座の幅 10 が約 60 m の川辺）。高い木は 3〜4.6 単位
- **地面の塊**：シリーズの砂や大理石の台の代わりに、厚さ約 1.55 の地面の塊（淡い茶色の表土と、淡いクリーム色の石灰岩の層の切り口）。上面の高さは地形に合わせて変わる
- **川**：シリーズの海と同じ水の描き方を、高さの違う 4 つの水面（湧き水の池・滝のあいだの 2 つの池・下の川）と、流れに沿って動くさざ波・滝つぼの泡・滝の水の幕に広げた

## 作りのあらまし

| ファイル | 内容 |
| --- | --- |
| `src/config.ts` | すべての値（地形・川・岩・植物・恐竜を置く場所・倒木・光・カメラ） |
| `src/terrain/layout.ts` | 地形：川の中心線（Catmull-Rom）と、それに沿って重ねた円で求める川の範囲・幅・深さ、U 字の谷、岸の斜面、砂浜と右岸の砂地、右奥の高台の斜面と滝の段。格子に焼いて速く読む |
| `src/terrain/mesh.ts` ・ `materials.ts` | 上面の網目と外周の切り口。地面（苔・草・土・砂・濡れた砂・川底・滝のまわりの濡れた岩肌）と切り口（表土と石灰岩。外周に沿って継ぎ目なく続く石組み）のシェーダー |
| `src/river/` | 水面・断面・滝の幕のシェーダー（シリーズの海の描き方をもとに、流れの向きのさざ波・岸と滝つぼの泡を加える） |
| `src/rocks/` | 岩の形のひな形（距離関数をメッシュにする）と、岸・水の中・川底の岩、小石 |
| `src/plants/` | 木と下草のひな形と配置。木の枝葉は、葉の形を描いたテクスチャの板（針葉樹の枝先・広葉樹の葉の房）を何百枚も重ね、法線を樹冠の外向きに寄せてやわらかく陰影づける |
| `src/props.ts` | 右岸の倒木 |
| `src/dinoSpots.ts` | 恐竜を置く場所のまわりに植物を置かない範囲 |
| `src/lightBaker.ts` ・ `bakedLighting.ts` | 影と空からの遮蔽の焼き込み（シリーズ共通） |
