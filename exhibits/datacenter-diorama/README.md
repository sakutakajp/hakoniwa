# データセンター（通常版）

Sites project `appgprj_6ad38f4230a48191b6a580427ce96136` の通常版 v2、commit `48d053390fb2ee5c866c502fe65c3c1aeb799dce` を移植。親タスクから受領した18ファイルすべてをSHA-256照合してから編集した。受領時のハッシュは `source-manifest.json` に記録する（移植後ファイルのハッシュではない）。ネオン版・外部Siteへの埋め込みは含まない。

`src/datacenter.ts` の形状は受領ソースと同一。サーバーラック20台、空調、配電盤、二重床の配線は実行時に生成され、画像・モデル・外部フォントの取得はない。

移植変更: 相対エントリーパス、シリーズ共通ホームカメラと台座基準の構図、共通操作API、動きを抑える設定、非表示時の描画停止、終了時のRAF・イベント・タイマー・GPU資源解放、初期化失敗/コンテキスト喪失の再試行。操作中の解像度変更は既存展示同様に行わない。軽量モード（明示指定またはソフトウェアGPU）のみ影の方向サンプルを主光4・補助光4・AO8、深度マップ512へ減らす。通常画質の設定と形状は変更しない。

依存は既存リポジトリの Three.js 0.186.1 を利用する。新規依存なし。Three.js のライセンスは共通ビルドで `exhibits/licenses/THREE-LICENSE.txt` に同梱する。提供されたアプリソースについて新たなライセンスは付与しない。

検証: `npm run typecheck:exhibits`、`npm run typecheck`、`npm run test:controls`、`npm run test:indexing`、`npm run build`。
実ブラウザ: ローカルビルドを起動し `BASE_URL=http://127.0.0.1:3159 node tests/controls/datacenter-browser.mjs`。デスクトップ幅/モバイル幅で読み込み、失敗後の再試行、キーボード/ボタン操作、reduced motion、コンテキスト喪失、戻るを確認する。

本体への導入には、検証済みLayerコミットへ依存pinを更新する別変更が必要。stagingや配信用PRをこの展示追加だけで更新しない。

## 検証環境の制約

Linux Chromium / SwiftShader（900×650・軽量モード）で初回表示を確認した際、GPU完了まで約90秒を要した。通常のGPU・Safari・Firefox・実機タッチ操作は未測定。約58万頂点の起動時生成を引き継いでいるため、低速環境向けの事前生成やワーカー化は今後の検討事項。読み込み完了は描画要求の送信ではなくGPUフェンスの完了で判定する。
