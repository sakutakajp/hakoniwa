# Sand Pedestal

暖かいベージュの床に置かれた、角丸の透明な水の塊（薄い土台の上の小さな海）を Three.js で描画する Web ページです。
海の中には、左の尾根から奥を回って右の岬へ続く C 字形の石灰岩の島があり、内側の入り江に白い砂浜があります。
島の上は森に覆われ、尾根には細い小道が通り、岬の足もとには海食洞があります。波打ち際には大きな岩が並び、
海底には藻をまとった茶色〜オリーブの岩が群れています。水は入り江の浅瀬（淡いエメラルド〜ターコイズ）から沖の深場（深い青）へ色が変わり、
側面のガラスのような断面は、水面の近くの青緑（沖は濃い青）から下の海底の明るい色へなだらかに移り、海底の砂と水中の光の網目、岩が透けて見えます。
箱庭はドラッグで回したり、拡大縮小したりして、好きな向きから眺められます。
砂・島の形と岩肌・植生・岩・海・影はすべて起動時にその場で生成するので、外部の画像素材は使いません。

## 起動手順

Node.js 20.19 以上（または 22.12 以上）が必要です。

```bash
npm install
npm run dev       # 開発サーバー（表示された URL をブラウザで開く）
npm run build     # 型チェック + 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果の確認
```

表示には WebGL2 に対応したブラウザ（最近の Chrome / Safari / Firefox / Edge）が必要です。

### 操作

| 操作 | マウス・トラックパッド | タッチ | キーボード |
| --- | --- | --- | --- |
| 回す（まわりを回る・見下ろす角度を変える） | ドラッグ | 1 本指でドラッグ | ← → で回す、↑ ↓ で傾ける（Shift で大きく） |
| 拡大縮小（指した所に向かって） | ホイール・ピンチ | 2 本指でピンチ | ＋ ／ − |
| 平行移動 | 右ドラッグ・Shift＋ドラッグ | 2 本指でドラッグ | — |
| 元の向きに戻す | ダブルクリック | ダブルタップ | 0 または Home |

キーボードで操作するときは、画面を一度クリックするか Tab キーで選んでから押します。
手を離すと少し惰性で回り、なめらかに止まります（動きを減らす設定のときは惰性なしで、すぐに合わせます）。
元の向きでは参考画像と同じ構図で、回すにつれて、どの方位から見ても台座全体が収まる構図へなめらかに移ります。
最初に開いたときだけ、画面の下に操作の案内が出ます（一度触ると、次からは出ません）。

### 確認用の URL パラメータ

画面には操作の案内のほかに UI を置いていません。確認したいときは URL の末尾に付けます。

| パラメータ | 内容 |
| --- | --- |
| `?az=-12&el=27` | 始める向き（方位角・仰角、度）。既定は `config.camera` の 0 / 22.8（手前の辺の正面から）。指定すると台座全体が画面いっぱいに入り、元に戻す操作でもこの向きになる |
| `?hint=0` | 操作の案内を出さない |
| `?quality=high` / `?quality=low` | 画質を固定する。既定では GPU を使えない環境だけ自動で `low` になる |
| `?vegetation=0` | 植生（森・ヤシ・草・つる・尾根の小道）を隠した状態で表示する（影も植生なしで作る） |
| `?rocks=0` | 岩・緑の岩・小石・砂利を隠した状態で表示する（影と地表の砂利の模様も岩なしで作る） |
| `?sea=0` | 海（水面・側面の断面・泡・水中の光）を隠し、海底と岩・島の位置関係を確認する |
| `?seaTime=3` | 波・泡・水中の光の動きを止め、その時刻（秒）の状態で表示する（見比べ用） |

方向の目安（参考画像の 4 方向）：正面はパラメータなし、右 `?az=-12&el=27`、上 `?az=0&el=78`、後ろ `?az=-135&el=37`。
方位角は上から見て、0 = 手前（南）、90 = 右（東）、180 = 奥（北）、-90 = 左（西）です。

## 主な調整項目（`src/config.ts`）

島・海・岩・植生の位置と大きさは、台座の一辺を 1 とした比率です（中心が 0、x は右＝東、z は手前＝南が正）。

台座・砂・カメラ

- `pedestal.size / thickness / cornerRadius` … 一辺・土台の厚み・角丸半径（既定は 10 / 0.255 / 1.2）。水の塊の厚みは `sea.depth`
- `sand` … 砂の色、砂紋（`ripple`）と細かな砂粒（`grain`）
- `camera` … 見る向き（方位角・仰角）、距離、注視点の高さ、画角
- `framing` … 画面内の余白（正方形の画面で参考画像と同じ構図になる値）。`framingOther` は回したとき（と `?az` / `?el` で始めたとき）の余白。
  縦長の画面では台座と島をまとめて上下の中央に置きます
- `controls` … 見る向きの操作。`enabled`（false で固定の構図）、回る速さ、見下ろす角度と拡大の倍率の範囲、追いつく速さ、惰性の弱まり方、
  参考画像の構図から回したときの構図へ移る角度（`blendRange`）、最初の案内（`hint`）

島（`island`）

- `footprint` … 水面の高さでの外形 `[x, z, 崖らしさ, 張り出し]`。崖らしさ 1 は入り江側の切り立った崖、0 は外側の斜面
  （水際だけ岩壁で上は森の斜面）。間の値では崖らしいほど水際の岩壁が高い
- `crest` … 尾根の線 `[x, z, 水面からの高さ]`。`crestFalloff` で尾根から離れるほど上面を低くする
- `slope` … 外側の斜面（岩壁の高さの割合・斜面の幅・ふくらみ・幅の上限）。`cliff` … 崖の傾きと波に削られたくぼみ
- `flare / flarePower / shelf / underwater` … 水の中で外へ広がる岩くずの土台、水面のすぐ下の岩棚、水の中のこぶと根元にかかる砂（`underwater.sand`）
- `wallGap` … 水の中の島の土台を台座の縁（水の壁）から離す幅（水面のすぐ下 `top` から海底で `bottom` まで）。
  側面から見たとき、ガラスと土台の間に水の層が、下の方には海底の砂が見えます（水面より上の崖はそのまま）
- `cave` … 岬の足もとの海食洞の位置・高さ・大きさ
- `relief` … 形状の凹凸（地層の張り出し、縦の割れ目、柱状の溝 `flute*`、大きなふくらみ、ざらつき、上面の起伏）
- `surface` … 細かな質感（バンプ）の強さ。`colors / roughness / shadeTint / ao` … 岩肌の色、つや、陰の色、くぼみの陰影
- `groundCover` … 森の地面（岩壁より上の斜面と上面）を下草と苔の色にする（木の間から白い岩が見えないように）
- `seed` … 乱数シード。`voxelSize` … メッシュの細かさ（小さいほど細かいが、起動に時間がかかる）

植生（`vegetation`）

- `trees / palms / shrubs / ground` … 木・ヤシ・低木・草の高さ、間隔（小さいほど密）、置く最大の傾き
- `drape / ledges / vines` … 崖の縁から垂れかかる緑、崖の段差の草むら、垂れ下がるつる
- `trail` … 尾根の小道の道筋 `[x, z]`・幅・色（道の上には木を置かない）
- `colors / colorPatchSize / shading` … 葉の色（深緑・オリーブ・黄緑・葉先・幹・光沢）、色のまとまりの大きさ、樹冠の陰影。
  `shading.leafSize / leafBump / leafContrast / sheen` で、細かな丸いふくらみと斜めから見た面のやわらかい光沢（苔のような質感）を調整します
- `mask` … 植生を置く範囲（水面からの高さ、洞窟の入口を空ける広さ、除外範囲）

岩（`rocks`）

- `major` … 水際の岩 `[x, z, 大きさ, 形の番号, 向き, 苔]`。`emerge` で半分ほど水面から出す
- `coastBoulders` … 島の外側の海岸（西と北）の波打ち際に自動で並べる岩の数・大きさ・沖への離し方
- `submerged` … 水の中に沈んだ岩
- `corals` … 海底の岩を 1 つずつ置く `[x, z, 大きさ, 形の番号 0〜5, 向き]`。正面の参考画像の並び（左の手前から島の足もとへ続く大きな岩の
  密な集まり、間の小石だけの砂地、中央の右の小さな集まり、右の手前から少し奥まで広がる集まり）に合わせています。
  `coralScale` で大きさをまとめて変えられます
- `coralGroups` … 海底の岩の群れ `[x, z, 広がり, 数, いちばん大きな岩の大きさ]`（入り江の口と中、深場の入口）。
  群れの中ほどに大きな岩、まわりに小さめの岩を寄せる。`coralScatter` は群れに入らずにばらばらに散らす岩（既定は 0）
- `coralColors / coralShadeTint / coralSurface / coralCavity / coralShade` … 海底の岩の色（藻をまとった茶色〜オリーブ、上の面は黄土色がかった苔）、
  陰の面の照り返しの色、質感、くぼみの暗さ、陰の明るさ
- `seabedSink / sandLine` … 海底の岩を砂に埋める深さと、根元にかかる砂（高さ・濃さ・色）
- `seabedStones / pebbleAlgae / pebbleAlgaeColor / pebbleBrightness` … 海底の岩のまわりに散らす細かな石（数・大きさ・広がり・埋める深さ）と、
  小石に付く藻の量と色（茶色がかったオリーブ）、水の中での明るさ
- `clusters / cliffBase / cave / sizes / counts` … 小石と砂利を密集させる場所と量
- `colors / tints / surface / moss / sink` … 岩肌の色、岩ごとの色の違い、質感、苔、埋める深さ

海（`sea`）

- `depth` … 水の塊の厚み（土台の上面から水面まで）。`sandLayer` … 土台の上の砂の層の厚み
- `seabed` … 砂浜の外形（`beach`）と乾いた砂の高さ、沖へ深くなる距離、南の崖の前の浅い砂の裾（`apron`）、浅い所（`shoals`）、
  起伏をならす幅（`smoothing`）。`fan` は陸から沖へ扇のように広がる砂の斜面で、海底の深さまで下がる距離（`length`。大きいほどなだらか）、
  曲がり具合（`power`）、斜面の長さのばらつき（`noise`）、扇の開く向き（`direction`。島の裏へは広げない）
- `deep` … 深場（濃い青に見える沖）の範囲、境目のぼかし（`blur`）とゆらぎ（`warp`）、仕上げのぼかし（`soften`）、加える見かけの水深。
  濃い青と入り江の青緑の境目をもっとぼかしたいときは `blur` を大きくします
- `colors / colorDepths / clarity / absorption` … 水の色（浅瀬・中ほど・深場）と色が移り変わる水深、透明度、赤・緑・青の吸収の比
- `wallClarity / wallClear` … 側面の断面の見通しと、ガラスのすぐ奥が澄んで見える距離。
  `wallHaze / wallTint / wallReflection` は側面から見える海底や岩にかかる水の色の割合、全体に掛ける色、ガラスの映り込みの強さ
- `wallGradient` … 側面の縦のグラデーション。水面の近くほど厚い水を通して見るように色を付けます（赤から順に吸われ、水の中で散らばる光の色が加わる）。
  `topColor / topColorDeep` は散らばる光の色（通常の海の青緑・深場の濃い青）、`path` は水面のすぐ下で足す水の厚み、
  `range / rangeDeep` は薄くなり始める深さと消える深さ（側面の高さに対する割合。深場ほど深くまで濃い）、
  `unevenness / noiseSize` は境目のむら（混ざり方を不均一にする）、`near` はガラスのすぐ奥の物（手前の岩）にかける割合、
  `base` はガラスの奥に見える島の土台にまとわせる水の厚み、`deepFloor` は深場の下の方の海底をうっすら青くする厚み。
  海面の近くの色をもっと下まで残したいときは `range` の値を大きくします
- `waves` … うねり・さざ波・水面一面の細かな風浪（`wavelets`）。`foam` … 岸の泡の幅・量・速さ・網目の大きさ
- `caustics / reflection / refraction / rim` … 水中の光の網目、水面の反射、屈折、水の塊の上の縁の照り返し
- `algae` … 水の中の岩に付く藻の色と量。`floorShadow` … 水の塊が床に落とす影の濃さ
- `fps / lowPowerFps / msaa` … 動きの更新回数と、水中を映す画像のアンチエイリアス

光と影・床

- `lights.key / fill / ambient` … 主光・補助光・環境光の色、強さ、方位、高度、柔らかさ
- `shadow` … 影の濃さ・サンプル数・解像度
- `floor` … 床の色と明るさのグラデーション、台座のまわりの柔らかい影（`dropShadow`）
- `lowPower` … GPU を使えない環境（ソフトウェア描画）で自動的に使う軽量設定

数値を変えて保存すると、開発サーバーでは自動で再読み込みされ、島の形・植生・岩・影がその設定で作り直されます。

見る向きは、`start()` が返す `view` で読み書きできます：`view.get()` でいまの向き（`{ azimuth, elevation, zoom, panX, panY }`）、
`view.set({ azimuth: 90, elevation: 30 })` で変える（`{ animate: false }` ですぐに）、`view.reset()` で元に戻す、
`view.setEnabled(false)` で操作の受け付けを止めます（開発サーバーではコンソールから `__scene.view.set({ azimuth: -135 })` で試せます）。

植生の表示・非表示は、`main.ts` の `start()` が返す `setVegetationVisible(true / false)` で切り替えます。
影もその状態で作り直します（開発サーバーではブラウザのコンソールから `__scene.setVegetationVisible(false)` で試せます）。
`group.visible` だけを変えると影が残るので注意してください。岩は `setRocksVisible`、海は `setSeaVisible` で同じように切り替えます。

## 実装メモ

- **島の形**：3 次元の密度関数（岩の内側で正、外側で負）を格子上で評価し、Surface Nets で 1 枚の閉じたメッシュにしています。
  水面の高さでの外形からの距離と、尾根の線からの距離で決まる上面の高さを基本に、入り江側は切り立った崖、外側は水際の岩壁から
  森の斜面へ変え、地層の張り出し、縦の割れ目と柱状の溝、大小のふくらみ、岬の海食洞を加えています。水の中では外へ広がる
  岩くずの土台になり、藻の色に覆われます。2 次元の補助場は先に格子へ焼いておき、3 次元の評価は高さ方向の 1 列ずつまとめて行います。
- **参考画像との合わせ方**：正面の参考画像を基準に、台座の外形が画像と重なるようにカメラ（遠近・画角・位置）を最小二乗で合わせ、
  画像上の砂浜や崖のふもと、岩の位置を水面の高さへ逆投影して平面の座標を決め、尾根の高さは画像の上端の輪郭から求めています。
  4 方向の参考画像は互いに島の大きさや位置が少しずつ食い違っているため、正面を優先し、どの方向から見ても同じ 1 つの形にしています。
- **岩肌**：シェーダー内でワールド座標の 3D ノイズから細い地層の溝・割れ目・ざらつきを作って法線を傾け（バンプ）、
  地層ごとにアイボリー〜サンドベージュ〜薄茶を塗り分けています。岩壁より上の上を向いた面は下草と苔の色にし、
  水面より下は藻の色に寄せています。
- **植生**：島のメッシュの三角形から面積に比例して点を取り、高さと傾きで種類を分けています。緩斜面と上面は樹木（ところどころヤシ）、
  急な所は低木と草むら、崖の縁からは緑が垂れかかります。尾根の小道の上には木を置かず、細い帯を上面に沿わせて道を描いています。
  同じ形はひな形を InstancedMesh で使い回し、色は場所ごとの大きなまとまりで付けています。
- **岩**：水際の岩は位置を指定して半分ほど水面から出し、島の外側の海岸には外形に沿って自動で並べます。
  海底の岩は、塊を積み重ねたこぶの多い形のひな形を使い、正面の参考画像の並びに合わせて 1 つずつ置いています（等間隔の群れにしない）。
- **海**：不透明な物（土台・海底・島・岩・植生）を色と奥行きの画像に 1 回だけ描き、毎コマその画像を写した上に水面と側面の断面を描きます。
  目から海底までの水中の距離と水深から、海底の色を吸収と散乱で弱めつつ水の色を重ねるので、浅瀬では砂紋や岩がはっきり見え、
  深くなるほど青くかすみます。深場は見かけの水深を足して濃い青にしています。見かけの水深は深場らしさの 2 乗に比例させて始まりをゆっくりにし、濃い青への移り変わりを広くぼかしています。水面は、ゆるやかなうねりとさざ波に、
  繰り返し模様のテクスチャから作る細かな風浪を重ね（入り江の中は穏やか）、視線が浅いほど強い空の反射と日差しのきらめきを加えています。
  側面はガラスのすぐ奥ほど澄んで見え、その上に縦のグラデーションを重ねています。水面の近くほど厚い水を通して見るように、
  見ている物の色を赤から順に吸い、水の中で散らばる光（通常の海は青緑、深場は濃い青）を加えるので、水面の近くは鮮やかな青緑〜濃い青、
  下へ行くほど長くなだらかに海底の明るい色へ戻ります。境目は側面に沿った大小のノイズでゆらし、雲のようなむらにしています。
  手前の岩のようにガラスのすぐ奥にある物にはかけすぎず、遠くを見通す所ほど濃くしています。
  島の水の中の土台は台座の縁から離し（深いほど広く）、そのマテリアルは水の中の部分を色の画像の不透明度 0 で描いて印を付けています。
  側面はその印を読み、ガラスの近くに見える土台も遠くと同じように水の色に沈めるので、低い角度から見ても濁った岩の塊になりません。
- **泡と水中の光**：泡は岸からの距離のテクスチャに沿って、岸に接した所は白く、外側は網目のレースにしています。
  遠浅の砂浜にだけ寄せては返す波の線を付け、沖の側の台座の縁でも波が白く砕けます。水中の光の網目は、海底や岩の表面に光の来る向きから映し、
  深いほど弱めています。
- **影**：主光と補助光を大きさのある面光源とみなし、方向を少しずつ変えた平行光で深度マップを描いて平均しています。
  受け手は床・砂（高さのテクスチャで起伏を与えた平面）と、岩肌・植物・岩の各点です。水の中の影は薄くし、水の塊は床にだけ薄い影を落とします。
  床には台座のまわりの柔らかい影を加え、遠くの床は背景の色に溶け込ませています（縦長の画面でも床の端が見えない）。計算は起動時の 1 回だけです。
- **見る向きの操作**：カメラは注視点（台座の中心の少し上）のまわりを回り、画角とレンズのずらしで大きさと画面上の位置を決めます。
  元の向きでは参考画像と同じ構図（台座の外形と島の上端から求める）で、元の向きから離れるほど、見下ろす角度ごとに全方位から見た範囲を合わせた
  一定の構図へなめらかに移るので、回しているあいだに台座が伸び縮みしません。拡大と平行移動はその上に重ねています。
  描画は必要なときだけ行い、見る向きが変わっているあいだは毎コマ、不透明な物の画像も描き直します。描画が重い環境では、
  動いているあいだだけ解像度を下げ、止まると元の解像度で描き直します。
- **海底の形**：島は左から奥を回って右の岬へ扇形に入り江を囲むので、砂は陸から手前・右手前・右へ扇のように広がって
  なだらかに深くなります。浅い所（砂浜と崖のふもとの浅い棚）からの距離を、島の中を通らずに回り込んで測り（格子の上のダイクストラ法）、
  その距離で水深を「陸の近くはやや急で、沖へ行くほどゆるやかに海底へなじむ」曲線までに抑えています。斜面の長さは場所ごとに少し変えて
  等深線をきれいな円弧にせず、島の裏（西と北の海岸の沖）へは広げません。最後にぼかしてならしています（砂浜の水際の高さはそのまま）。
- **海底の岩**：正面の参考画像で見える岩の位置と大きさを、画像の上の点からカメラの光線を海底へ戻して平面の座標に直し、1 つずつ置いています
  （この箱庭は手前の左ほど海底の砂が高いので、ガラスから見える高さの範囲に合わせて縦方向を縮めてから戻しています）。
  入り江と深場の入口は群れで置き、岩のまわりには根元に近いほど多く細かな石を散らして、岩と石の集まりにしています。
  海底の岩と沈んだ岩は高さの 4〜5 割を砂に埋め、根元は海底の高さのテクスチャを読んで砂の色にしているので、砂から岩が顔を出しているように見えます。
  島の崖の真下（台座の縁で土台を離した所）や、足もと全体が浅い岩棚に載らない所には岩を置きません（水の底に沈んだ黒い塊にならないように）。
- **負荷**：海の動きは 1 秒あたり 30 回まで（GPU を使えない環境では 2 回まで）に抑え、ページが隠れているあいだは止まります。
  動きを減らす設定（prefers-reduced-motion）のときは波を止め、見る向きの操作も惰性なしにします。数の多い木の葉は、細分しない
  多面体の粒で作り、三角形を抑えています。デバイスピクセル比は 2 までに制限し、
  GPU を使えない環境では `lowPower` の設定に切り替えて起動時の生成を軽くします（形と配置は同じ）。
- **表示できないとき**：WebGL2 を使えないブラウザでは、画面中央に理由と対処を表示します。
