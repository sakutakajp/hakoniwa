# Library Diorama（図書館の箱庭）

暖かいベージュの床に置かれた、四隅の丸い正方形の大理石の台の上の、歴史ある図書館の箱庭を Three.js で描画する Web ページです。
「淡い砂の角丸ミニチュア台座」（`sand-pedestal`）・「ニューヨークの箱庭」（`nyc-diorama`）とシリーズになるように、
台座（一辺 10・四隅の半径 1.2・木地の土台）・床・光・トーンマッピング・画面と操作の作りをそろえています（縮尺は違います）。

- 手本：オックスフォードのコドリントン図書館（奥の壁の大きなセルリアーナの窓、2 段の本棚と回廊、斜めに張った 2 色の石の床と濃い縁取り）、
  ケンブリッジのレン図書館（本棚の上の高いアーチの窓、明るい石の壁、白黒の大理石の床）、ダブリンのロング・ルーム（回廊の下の金文字の帯）、
  アムステルダムのカイパース図書館やカオールの図書館（回廊へ上るらせん階段）の写真と記述をもとに、ゼロから組み直した
- 部屋：壁は奥と左だけ（同じ高さ）で、手前と右が開いた切り取り。奥の左の角は台座と同じ丸みで、外側も内側も同じ中心の弧で曲がる。
  壁の両端は切石の付け柱で終わり、壁の上には歯飾りのある軒の刳り形と笠石。外側は 2 階の高さにめくらアーチの窪みと帯石
- 1 階：両方の壁に、下に鏡板の戸棚、上に 5 段の本の棚が並ぶ明るい古材の本棚。区画の間の柱形に真鍮の燭台、本棚の前に梯子を掛ける真鍮の手すり。
  床は斜めに張ったクリームと灰色の大理石の市松に、開いた縁に沿う濃い石の帯と、手前のまん中の象嵌の方位の星。
  まん中にペルシャ絨毯と長い机、緑の色ガラスの笠のランプ 3 つと 6 脚の椅子。左の手前に緑の革の肘掛け椅子と黄色い笠のランプ、書見台、梯子。
  右に地球儀と天球儀の一対、右の手前にガラスの蓋の陳列台（彩色写本）、本の手押し車、花台の鉢植え
- 回廊：左と奥をめぐる L 字（真鍮の手すり子、柱は本棚の柱形の真上）。下の帯（鼻隠し）には区画ごとに学問の名（THEOLOGIA・PHILOSOPHIA・
  HISTORIA … GRAMMATICA・MATHEMATICA・ASTRONOMIA …）が金文字で入る（らせん階段の踊り場の陰になる区画は空ける）
- 2 階：左の壁にアーチの額縁の本棚が 1 階の区画の真上に並ぶ（2 階の本棚は左の壁だけ）。奥の石の壁には、まん中にセルリアーナ（中央のアーチの窓と
  両脇の四角い窓、間に細いイオニア式の柱）、両脇にアーチの窓。窓の間にイオニア式の柱頭の付け柱と燭台。上の軒は全部の本棚の上を 1 本で通る。回廊に机と鉢植え
- らせん階段：奥の右から回廊へ。柱から片持ちで出る扇形の段（段ごとの筒が柱に重なって節になる）、真鍮の手すり子、らせんの木の手すり。
  いちばん上の段は回廊の高さの踊り場
- 光：奥の少し右からの日が奥の窓から手前へ差し込み、淡い光の筋（`src/room/sunbeams.ts`）になって、長机・椅子・敷物・肘掛け椅子に窓の形の光を落とす。
  机のランプと壁の燭台は、まわりをほんのり照らす
- 本：約 2,100 冊。革装の背バンド・布装の箔押し・紙の題簽など 6 種の装丁を、シェーダーで描く

箱庭はドラッグで回したり、拡大縮小したりして、好きな向きから眺められます。
本の背・木目・大理石の床と方位の星・金文字・絨毯・地球儀と天球儀の模様と影はすべて起動時にその場で生成するので、外部の画像素材は使いません。

## 起動手順

Node.js 20.19 以上（または 22.12 以上）が必要です。

```bash
npm install
npm run dev       # 開発サーバー（表示された URL をブラウザで開く）
npm run build     # 型チェック + 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果の確認
```

表示には WebGL2 に対応したブラウザ（最近の Chrome / Safari / Firefox / Edge）が必要です。

### 操作（シリーズ共通）

| 操作 | マウス・トラックパッド | タッチ | キーボード |
| --- | --- | --- | --- |
| 回す（まわりを回る・見下ろす角度を変える） | ドラッグ | 1 本指でドラッグ | ← → で回す、↑ ↓ で傾ける（Shift で大きく） |
| 拡大縮小（指した所に向かって） | ホイール・ピンチ | 2 本指でピンチ | ＋ ／ − |
| 平行移動 | 右ドラッグ・Shift＋ドラッグ | 2 本指でドラッグ | — |
| 元の向きに戻す | ダブルクリック | ダブルタップ | 0 または Home |

元の向きは右手前から（方位 22°）の構図です。仰角・画角・距離はシリーズと同じ（22.8° ／ 13.44° ／ 台座の幅の 4.86 倍）。
回すにつれて、どの方位から見ても台座全体が収まる構図へなめらかに移ります。
最初に開いたときだけ、画面の下に操作の案内が出ます（一度触ると、次からは出ません）。

### 確認用の URL パラメータ

| パラメータ | 内容 |
| --- | --- |
| `?az=0&el=22.8` | 始める向き（方位角・仰角、度）。既定は `config.camera` の 22 / 22.8（`az=0` でシリーズと同じ正面の向き） |
| `?hint=0` | 操作の案内を出さない |
| `?quality=high` / `?quality=low` | 画質を固定する。既定では GPU を使えない環境だけ自動で `low`（影の焼き込みを軽く）になる |
| `?light=key` / `fill` / `sun` / `ambient` | その光だけにする（光ごとの効き方と影の焼き込みの確認用） |

## シリーズの共通仕様（ほかの箱庭と同じ所）

| 項目 | 内容 | 設定・ファイル |
| --- | --- | --- |
| 台座 | 一辺 10 の正方形、四隅とも半径 1.2。下に厚さ 0.255 の明るい木地の土台（`#a58c6a`、角の丸み）、その上に大理石の台 | `config.pedestal`、`config.room.base`、`src/pedestal.ts` |
| 床 | 暖かい淡いベージュ（`#e2d6cf`）。遠くは背景の色（`#fae8d4`）に溶け込み、台座のまわりに柔らかい影 | `config.floor`、`config.renderer.background`、`src/floor.ts` |
| 光 | 右手前の高い所からの柔らかい主光、右奥からの補助光、空と床の色の半球光。影と空からの遮蔽は起動時に焼き込む | `config.lights`、`config.shadow`、`src/lightBaker.ts`、`src/bakedLighting.ts` |
| 仕上げ | 明るい所だけを丸めるトーンマッピング | `config.renderer`、`src/toneMapping.ts` |
| カメラと構図 | 仰角 22.8 度・画角 13.44 度・距離は台座の幅の 4.86 倍。元の向きは参考画像と同じ余白（左右 5%・上 8%・下 12%）で、台座と壁の上端が収まるように合わせる | `config.camera`、`config.framing`、`src/framing.ts` |
| 画面と操作 | 背景・案内文の色、操作の案内、見る向きの操作 | `index.html`、`src/style.css`、`src/viewControls.ts` |

違うのは次の所です。

- **縮尺**：1 単位がおよそ 1 m（机の高さ 0.8、回廊の床 3.48、壁の上端 6.4）。台座の幅 10 が部屋の幅になる
- **元の向きの方位**：シリーズは手前の辺の正面（0°）、この箱庭は奥と左の壁がよく見える右手前の 22°
- **窓の日差し**（4 つ目の光）：焼き込みのテクスチャの A に、窓の日差しが遮られる割合を入れる。
  部屋の上と開いた右、奥の壁の右の端の先に見えない覆いを置いて焼くので、窓を通った光だけが部屋に入る。台座の外の床と土台には当てない（`uDirMask`）
- **部屋の中の光の効き**（`config.lights.interior`）：開いた手前と右から入る主光・補助光・空の光を部屋の中だけ少し弱め、暖かい色に寄せる。
  壁の外側・台・床はシリーズのまま
- **灯り**：机のランプと燭台は影を付けない点の光（空からの遮蔽で狭い所ほど弱める）。灯りと窓のまわりに光のにじみ（加算の板）
- **映り込み**：真鍮・金箔・ニス・磨いた石だけに、部屋の環境（暗い木の本棚・明るい窓・開いた手前と右・燭台の小さな光の点）を映す
  （`createInteriorEnvironment`）。拡散光には使わない

## 質感の作り方

本・木・大理石・床などは、次の技法を手続き的なシェーダーに取り入れて描いています。
細かな模様は 1 画素より細かくなったら平均の値に置き換え（帯域制限）、遠くでちらつかないようにしています。

| 質感 | 作り方 | 参考 |
| --- | --- | --- |
| 木目（本棚・回廊・階段・机） | 年輪を「丸太の芯からの距離」の等高線として描く。芯を板の面の下に置き、板の長さの向きに少し傾けると板目の山形（カテドラル）が出る。年輪のゆがみ、晩材の暗い細い帯、繊維の筋、導管の点、板の長さの向きの大きなむら（杢）を重ね、部品と板ごとに芯の位置・色（少し赤い板・黄色い板）を変える。晩材と目地はつやを鈍くする | Octane の Woodgrain の各パラメータ（年輪の数・ゆがみ・木目）、Liu ら「Simulating the structure and texture of solid wood」（年輪・導管・成長のゆがみ） |
| 古材の仕上げ | 明るく色の抜けた木の色に、箱の角のすれ（ニスがはげて明るい木地。所々だけ、つやも鈍く）と、むらのある色あせ（少し灰色がかった黄味へ寄せる）を重ねる。古いニスのつやは鈍く | — |
| 大理石・切石 | ドメインワープ（fBm の入力を別の fBm でずらす）で雲のようなむらを作り、細かな海綿状の粒、小さな濃い斑（化石の欠片・気孔）、ワープした fBm の等高線の細い筋を重ねる。石ごとに模様の場所と色を変える。目地は箱の端に半分だけ出ないようにする | Inigo Quilez「domain warping」、Shader Lab「procedural marble」（ゆがめた正弦の帯の \|sin\| のくぼみを筋にする） |
| 大理石の床 | 45° に回した正方形の格子で、クリーム（ボッティチーノ）と灰色（バルディリオ）の石を市松に張る。石ごとに模様の場所と色を変え、雲のむら・筋・細い目地。床の縁（角の丸い正方形）までの距離で、淡い余白・濃い石の帯・淡い細線・濃い細線の縁取りを描く。磨いた面のつやと映り込み | コドリントン図書館の床（斜めに張った 2 色の石と黒い大理石の縁） |
| 方位の星 | 4 本の長い光・8 本の斜めの光・16 本の小さな光を重ね、光ごとに中筋で明るい半分と陰の半分に分ける（光は中心からの角度ごとの凧形）。外に濃い石の輪 | — |
| 金文字の帯 | 回廊の鼻隠しの濃い木の帯に、区画ごとの学問の名を Canvas に描いた字の形（アルファ）で金箔にする（金属として映り込み、箔のむらとすれ）。区画の間の柱形の上は花の飾り | ロング・ルームの回廊の下の金文字の帯 |
| 本 | 背の丸み（法線を左右へ傾ける）、背バンドの盛り上がり（法線を上下へ傾ける）、箔押しの線・題名・飾り（金属として映り込む）、色革の題簽・古びた紙の題簽、革の型押し・布の織り目、背の端と天地のすれ、日焼け。上の棚との距離で背の上の方を暗くし（棚の中の空からの遮蔽）、頁の天は上の棚の陰に入る所を暗くする | State Library of NSW「Book spines」（背バンド・区画・箔押し・色革の題簽）、University of Edinburgh「band titles」 |
| 真鍮・金箔 | 金属の色（F0）は物理ベースの値（金 ≈ (1.0, 0.77, 0.34)）に近い金色。金属の見え方は映り込む環境で決まるので、暗い部屋に明るい窓と灯りの点がある環境を映し、手すり子はふくらみとくびれのある形にして光の点を作る | Unreal Engine「物理ベースのマテリアル」の金属の BaseColor の表 |
| 絨毯 | 地・メダリオン・吊り飾り・四隅の飾り・主の縁・細い縁・房の構成。地は菱形の格子とロゼットと葉の総柄、縁は唐草でつないだロゼットとパルメット、細い縁は互い違いの三角。手織りの色むら（アブラッシュ）、結び目のむら、浅い角度で明るくなる毛足 | Nazmiyal「Rug anatomy」 |
| 箱の辺 | 棚板・框・柱形・手すり・石の角などの箱の面は、辺から 0.012 以内で法線を外へ傾け、丸めた辺が光を受ける細い線にする（Blender の Bevel シェーダーと同じ考え方。面の向きは辺までの距離の画面上の変化から求める） | — |
| 日差しの筋 | 窓の中の数か所から日差しの進む向きへ細長い帯を伸ばし、帯は軸のまわりで回していつも見ている人の方へ向ける（光の柱やレーザーの描き方）。加算で淡く、窓の近くで濃く床へ向かって消え、縁はぼかしてほこりのむらを入れる | — |
| その他 | 色ガラスの笠（なめらかな曲面・つや・下の縁の透け）、革（むら・型押し・つやのむら）、地球儀（黄ばんだ海に古地図のような淡い色の大陸）、天球儀（藍の地に金の星・星座の線・黄道の帯）、陳列台のガラス（影を落とさない透明な板に部屋の映り込み、真鍮の縁）と彩色写本（金箔の頭文字・朱と藍の挿絵・字の行） | — |

## 調整の手がかり

- 部屋の寸法（壁・回廊・本棚・窓の位置と高さ・らせん階段）：`config.room`（本棚の区画の幅は、窓の間の柱形の位置から決まる）
- 色：`config.colors`（木・大理石・絨毯・真鍮など）、本の背の色と並び方：`config.books`
- 木目の強さ・年輪の間隔・つや：`src/room/styles.ts` の `vein`・`ring`・`roughness`（木の仕上げ）
- 大理石のむら・筋：`src/room/styles.ts` の `mottle`・`vein`（石の仕上げ）
- 大理石の床（敷石の大きさ・2 色・縁取り・方位の星）：`config.marbleFloor`、箱の辺の丸み：`config.bevel`
- 金文字の学問の名と金の色：`config.inscription`
- 日差しの筋の色・濃さ・長さ：`config.sunbeams`、窓の位置と大きさ：`config.room.windows`
- 映り込みの環境と強さ：`config.lights.reflection`
- 窓の日差し：`config.lights.sun`（方位・高さで床の光の位置が動く。いまは奥の少し右から長机へ。`softness` を小さくすると窓の格子がくっきりする）
- 部屋の中の明るさと色：`config.lights.interior`
- 灯り：`config.lamps`
- 画質と起動の速さ：`config.shadow`（焼き込みの標本数と解像度）、`config.lowPower`
- シリーズ共通の値（`pedestal`・`lights` の主光・補助光・環境光・`shadow`・`floor`・`renderer`・`camera` の仰角・画角・距離・`framing`・`controls`）は、ほかの箱庭と同時に変える
