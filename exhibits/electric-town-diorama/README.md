# Electric Town Diorama（電気街の箱庭）

暖かいベージュの床に置かれた、四隅の丸い正方形の路面の塊の上の、夕暮れの電気街の交差点の箱庭を Three.js で描画する Web ページです。
「淡い砂の角丸ミニチュア台座」（`sand-pedestal`）・「ニューヨークの箱庭」（`nyc-diorama`）・「図書館の箱庭」（`library-diorama`）・
「ジュラ紀の川辺の箱庭」（`dino-diorama`）とシリーズになるように、台座（一辺 10・四隅の半径 1.2・木地の土台）・床・光の向きと強さ・
トーンマッピング・カメラ・画面と操作の作りをそろえています（縮尺は違います）。

- 手本：ご提供いただいた参考画像（夕暮れの電気街の交差点のミニチュア）。カメラは参考画像の台座の外形に合わせて求め、シリーズの仰角と画角のまま、少し左手前（方位 −9°）から見る
- 路面の塊：灰色のアスファルトとコンクリートの塊。手前は雨に濡れた車道が V 字に分かれ（白線・破線・横断歩道・マンホール）、奥は縁石で一段高い石畳の歩道
- 街区：中央の路地をはさんで左右に雑居ビル（18 棟、どれも長方形）。どの建物も通り・広場・路地・裏路地のどれかに面して入口があり、
  タイル・青い金属パネル・ガラスの売り場の外壁、窓の明かりと部屋の奥行き、明るい店先、お店の色の日よけ
- 看板：32 軒の架空のお店（名前・英字の添え書き・色・自作のロゴ）。1 階のお店は店先の上の横長の看板、上の階のお店は店名と階を書いた袖看板、
  大きな縦長の看板はお店のロゴの下に売り物の絵記号、赤いネオンの帯は縦書きの店名。お店の名前もロゴもすべて架空で、実在の店名やロゴは使っていません
- 屋上：室外機、冷却塔、給水タンク、換気の筒、アンテナ、手すり、階段室、植え込みの木、鉄塔
- 通り：街灯、街路樹、電柱と電線、車止め、低い柵、自転車、配電箱、自動販売機、売店、店先の商品の棚、非常階段、壁の室外機、歩く人々（約 95 人）、白いワゴン車と黄色いタクシー
- 光：シリーズの光（右手前の主光・右奥の補助光・空と床の半球光）の向きと強さはそのままに、街の物だけ日差しを暖かく、空からの光を青く寄せて夕暮れらしくする。
  店先・街灯・看板・車の灯りは「街の明かり」として地面と壁を照らし、濡れた路面に縦に伸びる光の筋になって映る

箱庭はドラッグで回したり、拡大縮小したりして、好きな向きから眺められます。
外壁・路面・看板の絵・葉の模様と影はすべて起動時にその場で生成するので、外部の画像素材は使いません
（看板の書体だけは、使う文字に絞った書体をコードに埋め込んでいます。下の「看板の書体」）。

## 街のつくりのルール

参考画像の見た目をなぞるだけだと、上から見たときに街として成り立たない所が出ます。この箱庭では次のルールで作っています。

1. **車道の幅は一定**：左右の通りとも、縁石から向かいの縁石まで 2.3（2 車線と路側帯）。中央の破線は幅のちょうど真ん中、外側線は両側の縁石から 0.25。
   車道の先（手前）は向かいの歩道で、台座の縁で切れる（`config.town.road.width`、`config.town.lanes`）
2. **建物はすべて長方形**：面している道の向きの枠（左の通り `L`・右の通り `R`・路地 `A`）で、道に沿った範囲 s と道からの奥行き d を決めて作る（`src/town/plan.ts` の `boxL`・`boxR`・`boxA`・`boxAEnd`）
3. **どの建物も道に面する**：通り・交差点の広場・路地・裏路地（`config.town.backLanes`）のどれかに、入口のある面（面 0）が面する。路地は突き当たりの建物まで、裏路地は台座の縁まで続く
4. **看板はお店ごと**：建物ごとに何階に何のお店が入っているかを決め（`src/town/features.ts` の先頭の表）、1 階は店先の看板と日よけ、上の階は袖看板（階の表示つき）を付ける

上から見た配置は、平面の図で重なり・台座の縁からの距離・それぞれの面の外が道につながるかを確かめてから 3D にしています。

## 起動手順

Node.js 20.19 以上（または 22.12 以上）が必要です。

```bash
npm install
npm run dev       # 開発サーバー（表示された URL をブラウザで開く）
npm run build     # 型チェック + 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果の確認
```

表示には WebGL2 に対応したブラウザ（最近の Chrome / Safari / Firefox / Edge）が必要です。
起動時に影と空からの遮蔽を焼き込むので、表示までに数秒かかります（GPU のない環境では軽い設定に切り替わります）。

### 操作（シリーズ共通）

| 操作 | マウス・トラックパッド | タッチ | キーボード |
| --- | --- | --- | --- |
| 回す（まわりを回る・見下ろす角度を変える） | ドラッグ | 1 本指でドラッグ | ← → で回す、↑ ↓ で傾ける（Shift で大きく） |
| 拡大縮小（指した所に向かって） | ホイール・ピンチ | 2 本指でピンチ | ＋ ／ − |
| 平行移動 | 右ドラッグ・Shift＋ドラッグ | 2 本指でドラッグ | — |
| 元の向きに戻す | ダブルクリック | ダブルタップ | 0 または Home |

最初に開いたときだけ、画面の下に操作の案内が出ます（一度触ると、次からは出ません）。

### 確認用の URL パラメータ

| パラメータ | 内容 |
| --- | --- |
| `?az=-9&el=22.8` | 始める向き（方位角・仰角、度） |
| `?hint=0` | 操作の案内を出さない |
| `?quality=high` / `?quality=low` | 画質を固定する。既定では GPU を使えない環境だけ自動で `low`（影の焼き込みと映り込みを軽く）になる |
| `?town=0` | 街（建物・看板・小物・人・車）を隠した状態で始める（路面の塊だけ） |
| `?reflection=0` / `?bloom=0` | 濡れた路面の映り込み・光のにじみを止める |
| `?bake=0` | 影の焼き込みを省く（配置の確認用。速く表示できる） |
| `?debug=mass` | 建物の塊を色分けして、照明なしで描く（配置の確認用） |
| `?debug=light` | 街の明かりの地図を路面に表示する |
| `?refcam=1` | 参考画像（1254 × 1254）と同じカメラで描く（並べて比べる用） |

## シリーズの共通仕様（ほかの箱庭と同じ所）

| 項目 | 内容 | 設定・ファイル |
| --- | --- | --- |
| 台座 | 一辺 10 の正方形、四隅とも半径 1.2。下に厚さ 0.255 の明るい木地の土台（`#a58c6a`、路面の塊より一辺の 1.2% 内側） | `config.pedestal`、`src/pedestal.ts` |
| 床 | 暖かい淡いベージュ（`#e2d6cf`）。遠くは背景の色（`#fae8d4`）に溶け込み、台座のまわりに柔らかい影 | `config.floor`、`config.renderer.background`、`src/floor.ts` |
| 光 | 右手前の高い所からの柔らかい主光、右奥からの補助光、空と床の色の半球光。影と空からの遮蔽は起動時に焼き込む | `config.lights`、`config.shadow`、`src/lightBaker.ts`、`src/bakedLighting.ts` |
| 仕上げ | 明るい所だけを丸めるトーンマッピング | `config.renderer`、`src/toneMapping.ts` |
| カメラと構図 | 仰角 22.8 度・画角 13.44 度・距離は台座の幅の 4.86 倍。台座と建物の上端が余白に収まるように合わせる | `config.camera`、`config.framing`、`src/framing.ts` |
| 画面と操作 | 背景・案内文の色、操作の案内、見る向きの操作 | `index.html`、`src/style.css`、`src/viewControls.ts` |

違うのは次の所です。

- **縮尺**：1 単位がおよそ 4 m（台座の幅 10 が約 40 m の交差点）。人の背は約 0.44、雑居ビルは 3〜5 単位（4〜7 階建て）
- **向き**：参考画像に合わせて、少し左手前（方位 −9°）から見る
- **路面の塊**：シリーズの水の塊の代わりに、厚さ約 1.05 の灰色の路面の塊（車道は床から 1.3、歩道は 1.35）
- **夕暮れの色調と街の明かり**：光の向きと強さはシリーズのまま、街の物だけ日差しを暖かく・空からの光を青く寄せる。
  店先・街灯・看板・車の灯りは、上から見た「街の明かりの地図」（HDR のテクスチャ）にまとめて、地面と壁の低い所を照らす
- **描画の流れ**：濡れた路面の映り込み（路面の高さの鏡に映した景色）→ HDR のシーン → 光のにじみ（ブルーム）→ トーンマッピング。
  映り込みは見る向きが変わったときだけ描き直す

## 看板の書体

看板の文字には次の書体を使っています。どれも [SIL Open Font License 1.1](https://openfontlicense.org) の書体で、看板に使う文字だけに絞って
（`pyftsubset`、WOFF2）`src/town/fontData.ts` に埋め込んでいます。ライセンスの全文と絞った書体のファイルは `fonts/` にあります。

| 書体 | 使う所 | 著作権 |
| --- | --- | --- |
| Dela Gothic One | 太いゴシックの店名 | Copyright 2020 The Dela Gothic Project Authors |
| DotGothic16 | ドットの店名（ピクセル堂・ジャンク横丁・ドット電脳・ハイスコア） | Copyright 2020 The DotGothic16 Project Authors |
| Zen Maru Gothic（Black） | 丸ゴシックの店名 | Copyright 2021 The Zen Maru Gothic Project Authors |
| RocknRoll One | 丸みのあるポップな店名 | Copyright 2020 The RocknRoll Project Authors |
| Bungee | 英字の添え書きと階の表示 | Copyright 2023 The Bungee Project Authors |

文字を足したときの作り直し方（Python の fonttools と brotli が必要）：

```bash
# 書体ごとに、看板で使う文字を text.txt に書き出してから
pyftsubset DelaGothicOne-Regular.ttf --text-file=text.txt --flavor=woff2 \
  --output-file=DelaGothicOne-subset.woff2 --name-IDs='*' --name-legacy --name-languages='*' --no-hinting --layout-features='*'
# できた WOFF2 を base64 にして src/town/fontData.ts の data を差し替える
```
