# NYC Diorama（ニューヨークの箱庭）

暖かいベージュの床に置かれた、角丸の透明な水の塊の中に浮かぶロウアー・マンハッタンの箱庭を Three.js で描画する Web ページです。
「淡い砂の角丸ミニチュア台座」（`sand-pedestal`）とシリーズになるように、台座・水の塊・床・光・カメラ・画面の作りをそろえています。

- 島：ワン・ワールド・トレード・センター（青いガラス・赤白のアンテナ）とエンパイア・ステート・ビルが奥に並び、
  緑の銅の屋根のボザール様式の塔、赤れんが・ベージュ・灰色のビル、屋上の木の給水タンク、池のある公園と並木、街灯・ベンチ・消火栓
- 道路：島を一周する海沿いの通り（手前は FDR ドライブ、奥はウェスト・サイド・ハイウェイ）、東西の大通り、南北の 2 本の通り。
  どの道も交差点か T 字路でつながり、行き止まりや水の上を走る所はない。黄色いタクシーは右側通行の車線の上
- ブルックリン橋：橋の通りの上の坂道（石の擁壁）→ 海沿いの通りをまたぐ石の桁 → 岸の石の橋台 → 川の中の石の主塔（尖頭アーチが 2 つ・星条旗）→ 台座の縁の切り口。
  主ケーブル・吊りケーブル・斜めのケーブル、路面の下のトラス
- 川：桟橋（ピア 17。杭の上のガラス張りの上屋）、白い航跡を引くフェリー
- 水の塊の側面（ガラスのような断面）から、川底の砂、主塔の基礎、桟橋の杭が透けて見える

箱庭はドラッグで回したり、拡大縮小したりして、好きな向きから眺められます。
建物の窓・地面の模様・砂・水・影はすべて起動時にその場で生成するので、外部の画像素材は使いません。

## 起動手順

Node.js 20.19 以上（または 22.12 以上）が必要です。

```bash
npm install
npm run dev       # 開発サーバー（表示された URL をブラウザで開く）
npm run build     # 型チェック + 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果の確認
```

表示には WebGL2 に対応したブラウザ（最近の Chrome / Safari / Firefox / Edge）が必要です。

### 操作（シリーズ共通）

| 操作 | マウス・トラックパッド | タッチ | キーボード |
| --- | --- | --- | --- |
| 回す（まわりを回る・見下ろす角度を変える） | ドラッグ | 1 本指でドラッグ | ← → で回す、↑ ↓ で傾ける（Shift で大きく） |
| 拡大縮小（指した所に向かって） | ホイール・ピンチ | 2 本指でピンチ | ＋ ／ − |
| 平行移動 | 右ドラッグ・Shift＋ドラッグ | 2 本指でドラッグ | — |
| 元の向きに戻す | ダブルクリック | ダブルタップ | 0 または Home |

元の向きはシリーズと同じ構図（手前の辺の正面から見下ろす）で、回すにつれて、どの方位から見ても台座全体が収まる構図へなめらかに移ります。
最初に開いたときだけ、画面の下に操作の案内が出ます（一度触ると、次からは出ません）。

### 確認用の URL パラメータ

| パラメータ | 内容 |
| --- | --- |
| `?az=-45&el=38` | 始める向き（方位角・仰角、度）。既定は `config.camera` の 0 / 22.8（シリーズの向き） |
| `?hint=0` | 操作の案内を出さない |
| `?quality=high` / `?quality=low` | 画質を固定する。既定では GPU を使えない環境だけ自動で `low`（影の焼き込みと砂の模様を軽く）になる |
| `?seaTime=3` | 波・泡・水の中の光・航跡の動きを止め、その時刻（秒）の状態で表示する（見比べ用。`?waterTime=` も同じ） |
| `?sea=0` | 水を隠して始める（川底・主塔の基礎・杭の位置の確認用） |

## シリーズの共通仕様（淡い砂の角丸ミニチュア台座と同じ所）

| 項目 | 内容 | 設定・ファイル |
| --- | --- | --- |
| 台座 | 一辺 10 の角丸の正方形（角の半径 1.2）。下に厚さ 0.255 の明るい木地の土台、その上に厚さ 2.18 の透明な水の塊 | `config.pedestal`、`src/pedestal.ts` |
| 水 | 水面・側面の断面・岸の泡・水の中の光の網目・深い所の濃い青。不透明な物を描いた画像に、水面と側面を重ねて描く | `config.sea`、`src/sea/*`（`shaders.ts` / `water.ts` は船の航跡だけを足した） |
| 砂 | 川底の砂の模様（風紋・粒）。水の中の影は薄く | `config.sand`、`src/sandTextures.ts`、`src/sea/seabed.ts` |
| 床 | 暖かい淡いベージュ。遠くは背景の色に溶け込み、台座のまわりに柔らかい影 | `config.floor`、`config.renderer.background`、`src/floor.ts` |
| 光 | 右手前の高い所からの柔らかい主光、右奥からの補助光、空と床の色の半球光。影と空からの遮蔽は起動時に焼き込む | `config.lights`、`config.shadow`、`src/lightBaker.ts` |
| 仕上げ | 明るい所だけを丸めるトーンマッピング | `config.renderer`、`src/toneMapping.ts` |
| カメラと構図 | 方位 0・仰角 22.8 度・狭い画角。台座の下の位置をそろえ、高い物が画面の上に近づくときだけ縮める | `config.camera`、`config.framing`、`src/framing.ts` |
| 画面と操作 | 背景・案内文の色、操作の案内、見る向きの操作 | `index.html`、`src/style.css`、`src/viewControls.ts` |

違うのは中身だけです：島は街（道路・建物・橋・桟橋）、ガラスや車のつやのある面には映り込み用の空（拡散光には使わない）、
川の色は「深い所らしさ」を島からの距離で決め、手前のガラスの近くは弱めています（`config.river`）。
2 本の超高層は高さだけ 0.82 倍に縮めています（模型の「選択的圧縮」。シリーズの構図で台座を小さくしすぎないように。`tools/design_layout.py` の `TOWER_SCALE`）。

## 配置の作り方（`tools/design_layout.py`）

街の配置（`src/layout.json`）は Python のスクリプトで作ります（shapely が必要）。

```bash
python3 tools/design_layout.py plan.png   # layout.json を書き、走行テストの結果と上から見た図を出す
```

- 島の外形 → 島を一周する海沿いの通り（岸から遊歩道の幅だけ内側）→ 大通りと南北の通り → 区画（島から道路を除き、角を丸める）の順に作る
- 建物は区画の通り側から歩道の幅だけ下げて置く。橋は坂道・桁・橋台・主塔・切り口の順の路面の高さで指定する
- **走行テスト**：道の端が交差点か台座の縁で終わるか、水の上を走らないか、建物が歩道や公園・ほかの建物に重ならないか、
  島のまわりに水があるか、橋の路面の勾配が 16% 以下かを調べる

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `tools/design_layout.py` / `building_templates.json` | 配置の設計と走行テスト（上を参照）と、建物の形のひな形（部品の組み合わせ。配置のときに新しい区画へ動かす） |
| `src/layout.json` / `layout.ts` | 街の配置：島の外形、道路の中心線と面、交差点、区画、公園、横断歩道、建物の部品、橋、桟橋、フェリー、木・街灯・消火栓・ベンチ・車の位置 |
| `src/config.ts` | 調整用パラメータ。前半はシリーズ共通（台座・砂・水・川底・光・影・床・カメラ）、後半は街（島・地面・建物・外壁の様式・橋・車・木など） |
| `src/main.ts` | 組み立て：台座・砂・島・街（地面の高さに置いたグループ）・水、照明、影の焼き込み、カメラと構図、描画の繰り返し |
| `src/sea/layout.ts` | 台座と水の高さ関係（`seaLevels`）と、川底の形・深い所らしさ（`createRiverLayout`） |
| `src/ground.ts` | 島の形（上面・護岸の石垣）、地面のテクスチャ（Canvas 2D で道路・線・横断歩道・歩道・公園・池を描く）、歩道の区画と芝生の段差 |
| `src/meshBuilder.ts` / `materials.ts` / `buildings.ts` | 外壁の模様の座標を持つ形の組み立てと、焼き込んだ影を使うマテリアル（窓の並び・ガラス・石積み・トラス・手すり）、建物の形 |
| `src/bridge.ts` | ブルックリン橋：坂道の擁壁・海沿いの通りの上の桁・岸の橋台・川の上の路面とトラス・主塔と基礎・ケーブル・星条旗 |
| `src/pier.ts` / `ferry.ts` | 桟橋（床・川底まで届く杭・手すり・ガラスの上屋）と遊歩道の手すり、フェリー（船底まである船体・客室・操舵室） |
| `src/trees.ts` / `cars.ts` / `lamps.ts` / `props.ts` | 並木と公園の木、タクシー、街灯、ベンチと消火栓（どれも InstancedMesh。影はインスタンスごとに焼き込む） |
| `src/environment.ts` | 映り込み用の空の環境マップ（ガラス・車・街灯のつやのある面だけに使う） |
| `src/pedestal.ts` / `sandTextures.ts` / `sea/*` / `floor.ts` / `lightBaker.ts` / `bakedLighting.ts` / `toneMapping.ts` / `framing.ts` / `viewControls.ts` | シリーズ共通の部品（砂の台座と同じもの） |

## 調整の手がかり

- 配置（道路・区画・建物の位置・橋の高さ）：`tools/design_layout.py` を直して実行する
- 川底：`config.river`（護岸の足もとの水深・深くなるまでの距離・深い所らしさの範囲と手前での弱め方）
- 護岸の石垣：`config.island`（水の上・水の中・藻の色）
- 建物の仕上げ：`config.buildings`、外壁の様式は `config.facades` と `config.wallColors`
- 木：`config.trees`（縁の光・透過・葉の房・樹冠の下側の暗さ）
- シリーズ共通の値（`pedestal`・`sand`・`sea`・`lights`・`shadow`・`floor`・`renderer`・`camera`・`framing`）は、砂の台座と同時に変える
