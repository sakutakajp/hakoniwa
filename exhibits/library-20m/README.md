# 図書館20m比較試作（未公開）

既存 `library-diorama` を保持した独立コピー。台座10 world unitsを20mとし、1 unit=2mで家具・棚・階段を組み直す。

`/library-comparison.html` は現行10m版と同じカメラ・同じ台座表示サイズで比較するローカルページ。PCは左右並列、スマホは同じ表示枠で切替。どちらからの回転・拡大も同期できる。`?quality=low` / `high` で品質指定。通常は各作品の既存GPU判定を利用する。

## 設計案

- 建物の外形、窓、光、カメラ、台座は保持。室内床から回廊5m、壁上端10.84mの大閲覧室とする。
- 主閲覧用の長机4卓・24席。各卓3.7×1.28m、机高0.8m、椅子座面0.46mを維持。回廊に4席、休憩用肘掛け椅子2脚。
- 原型の家具・本・ランプ・植物を部品ごとに0.5倍して配置。テクスチャ付き形状、インスタンスの本、灯りの位置と範囲も一緒に変換し、影焼き込み前に適用する。
- 下の棚11段、上の棚14段。棚の奥行き0.45/0.32m、中央仕切りを追加し、本の厚みを元の実寸に合わせる。下部の戸棚の戸高0.4m。入口扉は追加しない。
- 回廊の机は1.1×0.55m・高さ0.75mに見直す（元版の高さ0.56mから変更）。
- 階段は32段、蹴上げ0.15625m。外径3.2m、合計回転角240°を維持。回廊手すり1.1m、階段手すり1m。これらは比較用設計値であり、建築法規や避難計画の適合判定ではない。
- 高い棚には上下階の梯子を配置。梯子の幅と横木間隔を維持し、長さを棚高に合わせる。
- 各卓に実寸4.9×3.6mの敷物。床のタイル一辺0.6mを維持。

## 起動

リポジトリのルートで `npm ci`、`npm run build:exhibits`、`npm run dev`。`/library-comparison.html` を開く。生成済み `public/` はHTTPサーバーでも閲覧できる（file://で直接開かない）。

元の5作品と里山は変更していない。比較のため2つのWebGL contextを使用するので単独展示より負荷が増える。ページを離れると両方のsceneをdisposeする。比較用ソースを公開サイトへ反映する作業は含まない。
