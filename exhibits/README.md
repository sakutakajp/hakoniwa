## このリポジトリでの実行

このフォルダは作品ソースの保存先です。依存はリポジトリのルートで一元管理しています。ルートで `npm ci`、`npm run dev` を実行してください。統合の詳細は [統合資料](../docs/hakoniwa-integration.md) を参照してください。以下は提供時の原作の説明として保持しています。

## 原作の動かし方（どの作品も同じ）

Node.js 20.19 以上（または 22.12 以上）が必要です。

```bash
cd electric-town-diorama   # 見たい作品のフォルダ
npm install
npm run dev                # 開発サーバー（表示された URL をブラウザで開く）
npm run build              # 型チェック + 本番ビルド（dist/ に出力）
```

表示には WebGL2 に対応したブラウザが要ります。作品ごとの説明・操作・確認用の URL パラメータは、各フォルダの `README.md` にあります。
そのまま開ける 1 枚の HTML にまとめる方法は、手順書の 5.9 と付録 A-9 にあります。

## シリーズで共通の部品

どの作品も、次のファイルを同じ作りで持っています（値は `src/config.ts` の前半）。新しい作品は、いちばん近い作品のフォルダを写して中身だけを作り替えます。

| ファイル | 役目 |
| --- | --- |
| `src/config.ts`（前半） | 台座・床・光・影・トーンマッピング・カメラ・構図・操作の値（シリーズ共通） |
| `src/pedestal.ts` | 台座（一辺 10・角の半径 1.2）と木地の土台 |
| `src/floor.ts` | 床と、台座のまわりの柔らかい影 |
| `src/lightBaker.ts` ・ `src/bakedLighting.ts` | 影と空からの遮蔽の焼き込み（起動時に 1 回） |
| `src/toneMapping.ts` | 明るい所だけを丸めるトーンマッピング |
| `src/framing.ts` | 台座と中身が画面に収まる構図の計算 |
| `src/viewControls.ts` | ドラッグ・ホイール・ピンチ・キーボードで見る向きを変える操作 |
| `src/main.ts` | 組み立て。`window.__scene`（開発時に見る向きを変える操作用）、描画の準備ができたら `#scene` に `data-ready="true"`（電気街は `?refcam=1` で参考画像のカメラ） |
| `index.html` ・ `src/style.css` | 画面（背景 #fae8d4、案内文の焦げ茶 #6b4f3a、最初だけの操作の案内） |

水のある作品（1・2・4）は `src/sea/` または `src/river/` に水の塊と水の色の計算、5 は `src/town/` に通り・建物・看板・明かりをまとめています。
