# 図書館の本探し（比較試作）

ルート: `/play/library-books`。既存の10m図書館をiframeで利用し、原作と20m比較のソース・寸法・公開導線は変更しない。トップ以外の共通noindexを適用。

「本を探す」で机に視点を固定。実際の机上3冊の位置に、タップしやすいゲーム用のしおりを重ねる。星・森・海のヒントを順に読み、3冊見つけるとクリア。誤答はその場で再選択でき、時間制限・減点はない。正答後は次のヒントへ明示的に進む。クリア後は再挑戦でき、途中でも「箱庭を眺める」で視点と回転操作を戻す。

選択領域はスマホで52×66 CSS px以上。ゲーム中はiframeへのポインター入力とカメラ操作を無効化し、しおり上のドラッグも回答として扱わない。画面サイズ変更・タブ復帰では投影位置を合わせ直し、進行状態を保持する。鑑賞時はしおりを消す。離脱時にWebGLと監視処理を解放する。

検証: `npm run typecheck`、`npm run build`。本番プレビューを起動後、`BOOK_HUNT_URL=http://127.0.0.1:3015 npx playwright test --config playwright.book-hunt.config.ts`。開始・誤答・正答・クリア・再挑戦・終了・タブ復帰・ドラッグ誤操作・タップ領域・WebGL解放をPC/スマホで確認する。

描画は既存の軽量品質を利用。実機GPU・iOS Safari・本番配信は別途確認が必要。データセンターの統合とは独立した試作。
