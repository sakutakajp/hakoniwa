# みらい博物館：全体コンセプト

更新日：2026年10月19日

## 体験の軸

**人の発想が形になった世界を、旅して体験する。**

入口は海のある初期地球。岩石と水の環境、生命の変化を経て、人々の暮らし、都市、技術、文化へと進む。世界の成り立ちを箱庭の景色と小さな発見からたどり、その経験を自分で世界を育てる体験へつなぐ。

地球・生命の場面では自然の仕組みと変化を、人類以降では人々の発想と営みを見せる。秋葉原、ローマのコロッセオ、ロゼッタストーンも、「その場所やモノを通して、どんな発想・仕組み・営みに気づけるか」という同じ指針で選ぶ。

## 採用した方針

| 項目 | 方針 |
|---|---|
| 展示の規模 | 全100個の箱庭。現在の構成は10章×10個 |
| 入口 | 原始の海から、地球と生命の歴史をたどる |
| 順路 | 地域によるルート分岐を設けず、全員が共通の旅をたどる |
| 地域への出会い | 共通順路の中で各地の文化へ自然に移り、別地域の題材にも触れる |
| 時代の見せ方 | 大きな流れは時代順。同時代の別の土地へ移るときは「いつ・どこ」を示す |
| 多言語 | 表示言語と展示内容を独立させ、全言語で同じ展示と順路を共有する |
| 一つの箱庭の単位 | 一つの場所・時代・観察スケールに絞り、景色と発見を持たせる |
| 横幅の規格 | 台座の横幅が表す距離を50cm（0.5m）・10m・100m・500m・2kmの5段階に固定する。制作時の規則は[ビジュアル方針](visual-direction.md)を参照 |
| 歴史の先 | 自分で世界を育てる体験へつなぐ。切り替え方は今後設計する |
| 題材の扱い | 自然、日常の暮らし、建築、科学、創作、現代文化を同じ旅に含める |

国別に歴史を選ぶ画面は設けない。地域の分類や個数は、企画側が偏りを点検するために使う。順路が共通であることと、画面を自動で進めることは別の設計項目とする。

## 偏りを点検する指針

- 100個全体で、地域・時代・題材・描かれる人々の立場を確認する。地域の採用数に加え、何をどう描くかを点検する。
- 一つの展示を国や地域の文化全体の代表にせず、場所と時代を限定する。
- 農民、職人、商人、学ぶ人、移住する人、観客、演者など、場面を支える人々を描く。
- 交流、創造、便利さとともに、支配、強制労働、戦争、環境への影響も題材の背景として扱う。
- 史実、後世の記憶、解釈、説明用の模型、研究中の仮説を区別する。
- 現代の題材は制作時に基準年を決め、将来も更新できるようにする。

## 歴史をどう見せるか

基本は「景色に出会う → 触れて観察する → 一つの発見が残る → 次の景色へつながる」という体験案。長い説明を先に読ませるより、見せ場と観察から興味をつくる。

全体で台座、カメラ操作、光の感覚をそろえ、場面ごとに景色と観察スケールを変える。微生物や細胞は拡大した観察世界として扱う。同時代の別地域へ移るときは、場面が続けて表示されることを歴史上の因果関係と混同させない。

初期の海の下にも岩石の地殻と地形がある。002は海底地形が海面へ現れる場面として見せる。003の海底熱水と004の陸上熱水は、生命誕生の異なる候補環境を訪れる展示として扱う。具体的な観察操作や遷移は個別設計案を出発点に調整する。

## 決定・検討・実装の区別

| 状態 | 内容 |
|---|---|
| 決定済みの方向性 | 地球史から入ること、地域分岐を設けないこと、多言語で共通の旅にすること、100個にまとめること、育成へつなぐこと |
| 決定済みの縮尺規格 | 横幅50cm（0.5m）・10m・100m・500m・2kmの5段階。各箱庭は一つを選び、その範囲を切り取って構成する |
| 採用した暫定構成 | 10章の章立て、001〜100の題材と配分。今後の調整は一覧と個別設計を同時に更新する |
| 検討案 | タップ・視点変更・前後比較などの操作、短い導入演出、箱庭間の遷移 |
| ビジュアルの検討 | 001〜010のコンセプト画像を作成済み。質感の共通方針は[ビジュアル方針](visual-direction.md)に記載 |
| 今後決めること | 育成への切り替え時点、育成の自由度、歴史との行き来、各場面の具体的な復元時点と場所、自動進行の範囲 |
| 現在の実装 | 海の箱庭の表示、波の表現、視点操作、タップ時の吹き出し。詳細は[海のジオラマ](ocean-diorama.md)を参照 |

企画文書にある波紋、島の出現、生物、時代遷移、100個の展示、育成モードは、実装状況を別途確認して進める。現時点の海のジオラマの引き継ぎ資料に、実装済み機能と検証の範囲を記録する。
