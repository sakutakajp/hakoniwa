## 起動

既存のNuxtアプリと一緒に起動する場合:

```sh
npm ci
npm run dev
```

`http://localhost:3000/ocean-diorama/index.html` を開いてください。
Nodeの必要バージョンはルートの `package.json` に従ってください。

ジオラマだけ確認する場合（Python 3のみで起動可能）:

```sh
python3 -m http.server 8000 --directory public
```

`http://localhost:8000/ocean-diorama/index.html` を開いてください。
ES Modulesを使うため、HTMLのファイル直接開きではなくHTTP経由でアクセスします。

## ファイル

- `public/ocean-diorama/index.html`: 全画面表示、背景、吹き出しのCSS、起動処理。
- `public/ocean-diorama/src/createOceanScene.js`: 台座、海、照明、カメラ、波のGLSLシェーダー。
- `public/ocean-diorama/src/createOceanRenderer.js`: 描画コンテキストの生成と、低負荷設定での再試行。
- `public/ocean-diorama/src/oceanBubble.js`: 海面のタップ判定と吹き出し。
- `public/ocean-diorama/vendor/`: Three.js 0.180.0、OrbitControls、MITライセンス。Sitesで使っていたものを同梱しており、CDN・npmのThree.jsに依存しません。

## 現在の仕様

- 白い正方形の台座と青い海。台座の本体厚みは初版の2.5倍（1.375）。
- 16成分の波に異なる波長・方向・位相を与え、場所と時間で強弱を変化させています。これはシェーダーによる波の表現であり、流体ソルバーではありません。
- 海面のどこをタップしても、海面中央に「…」の白い吹き出しを表示。吹き出し本体と尻尾は濃い青で縁取り。
- 再度海面をタップ、または吹き出し自体をタップすると非表示。
- ドラッグはカメラ回転、ピンチ/ホイールはズーム。ドラッグ・複数指操作・長押しはタップとして扱いません。
- 画面上の操作説明・パラメータ調整パネル・一時停止/視点リセットボタンは、ユーザーの要望により削除済みです。
- 初期値は波の高さ0.28、速さ0.72、きらめき1.0。変更する場合は `createOceanScene.js` のuniform初期値を編集します。
- スマートフォンは水面分割100、ピクセル比上限1.35、シャドウマップ1024。非表示タブでは描画を停止します。
- 描画の初期化に失敗した場合は、アンチエイリアスなし・ピクセル比上限1・シャドウマップ512で再試行します。

## Safari向けの初期化対応

- GPUの選択はブラウザーに任せます。`high-performance`の指定は行いません。
- WebGL2コンテキストを生成できない場合は、新しいcanvasでアンチエイリアスを無効にして再試行します。途中で初期化に失敗したコンテキストは解放します。
- JavaScriptは同梱ファイルの相対URLから直接読み込みます。import mapを使わず、Three.jsの参照先を全モジュールで統一しています。
- ローカルモジュールのURLには`v=safari-1`を付け、修正前のファイルがキャッシュから読み込まれることを防ぎます。モジュールを更新する場合は、変更したファイルの参照URLのバージョンも更新してください。
- 読み込み失敗と描画の初期化失敗を区別して表示します。どちらも「WebGL非対応のブラウザー」とは判定しません。

## 次の開発で守ること

- 元の見た目を確認してから変更し、波が均一な間隔・方向で繰り返して見えないようにしてください。
- 操作説明やパラメータパネルは、依頼がない限り再追加しないでください。
- タップ波紋・壁で反射する波・水しぶきなどの物理機能は未実装です。
- Sites固有の `.openai/hosting.json` とGit認証情報は移行対象外です。このGitHubブランチの更新は既存Sitesへ自動同期されません。

## 検証状況

移行時にアプリファイルのバイト一致、JavaScript構文、ローカルimport先、Git差分を確認します。波の法線計算と台座内の波の範囲は以前の作業で数値確認済みです。
2026-10-14の修正ではChromiumのPC・スマートフォンサイズで、海の描画、タップによる吹き出しの表示と再タップでの非表示、縦横回転、描画コンテキストの消失からの復帰を確認しました。GPU指定を拒否する条件、アンチエイリアスを拒否する条件、最初のコンテキスト生成だけ失敗する条件でも起動できることを確認しています。モジュールの読み込み失敗とWebGL2を生成できない場合のエラー表示も確認済みです。型チェックと本番ビルドも成功しています。

iPhone 17 Pro / iOS 26.6.1のSafari実機では修正後の再確認が必要です。WebKitのテストブラウザーは実行環境のダウンロード制限により取得できませんでした。ドラッグ/ピンチ誤判定や実機のタブ復帰は未検証です。
